## 발견된 이슈

### Issue 1: 모바일 하단 버튼 텍스트 줄바꿈
- **심각도**: warning
- **재현 방법**: 375px 모바일에서 퀴즈 풀기 화면 진입
- **현상**: "건너뛰기" → "건너뛰\n기", "정답 확인" → "정답 확\n인" 으로 텍스트 줄바꿈
- **원인**: 버튼 컨테이너 너비 부족 — `whitespace-nowrap` 또는 `min-w` 처리 필요
- **스크린샷**: `mobile-button-overflow/01-overflow.png`

### Issue 2: "새 퀴즈 생성" 클릭 시 React 렌더링 에러
- **심각도**: warning
- **재현 방법**: 결과 페이지에서 "새 퀴즈 생성" 버튼 클릭
- **에러 메시지**: `Cannot update a component (BrowserRouter) while rendering a different component (ResultPage)`
- **원인**: `ResultPage` 렌더링 중 `navigate()` 호출 → React 렌더 단계 중 상태 업데이트 금지 위반
- **영향**: React가 동기 렌더링으로 복구하여 실제 동작은 정상이나, 성능·안정성 위험
- **수정 방향**: `navigate()` 호출을 `useEffect(() => { navigate('/') }, [])` 안으로 이동
- **스크린샷**: `new-quiz-console-error/console-errors.txt`
