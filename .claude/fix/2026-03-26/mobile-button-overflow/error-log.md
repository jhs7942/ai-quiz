# 모바일 퀴즈 하단 버튼 텍스트 줄바꿈

## 발생 환경
- 날짜: 2026-03-26 / 관련 파일: 퀴즈 풀기 페이지 하단 네비게이션 버튼 컴포넌트 / 브라우저: Chrome (Playwright)

## 증상
375px 모바일 해상도에서 퀴즈 풀기 화면 하단의 버튼 텍스트가 줄바꿈됨.
- "건너뛰기" → "건너뛰\n기"
- "정답 확인" → "정답 확\n인"

버튼이 원형에 가깝게 찌그러져 UX 훼손.

## 원인
하단 네비게이션 영역의 flex 컨테이너 너비가 375px에서 충분하지 않아,
버튼 텍스트가 `white-space: normal` 상태로 줄바꿈됨.

## 해결책
해당 버튼에 `whitespace-nowrap` (Tailwind) 또는 `white-space: nowrap` (CSS) 추가.
또는 버튼의 `min-width`를 지정하여 최소 크기 확보.

## 재발 방지
모바일 브레이크포인트(375px) 기준 퀴즈 페이지 하단 버튼 레이아웃 테스트 추가.
텍스트가 2글자 이상인 버튼에는 `whitespace-nowrap` 기본 적용 규칙 수립.
